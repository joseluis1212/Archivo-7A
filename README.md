# Archivo 7A · EL SOL NOS MIENTE

Registro colaborativo de anomalías detectadas durante eclipses solares.

## Descripción

Plataforma web para la documentación y reporte de fenómenos no catalogados observados durante eventos astronómicos. Cada testimonio, fotografía y sombra que no debería estar ahí.

## Características

- 🌑 Visualización interactiva de eclipses
- 📸 Sistema de subida de evidencias fotográficas
- 👥 Registro de testigos y anomalías
- 🔒 Interfaz inmersiva con estética clasificada

## Uso

Abra `index.html` en cualquier navegador moderno o visite el sitio publicado en GitHub Pages.

## Tecnologías

- HTML5
- CSS3 (variables CSS, animaciones, gradientes)
- JavaScript vanilla
- Fuentes: Anton, IBM Plex Mono, Special Elite
